# Iran Miner — GitHub-ready project

این مخزن برای بارگذاری در GitHub و استقرار وب‌اپ Python روی Render آماده شده است.

> **هشدار مهم:** این نسخه صرفاً نمایشی است. استخراج واقعی، پرداخت بانکی یا انتقال رمزارز انجام نمی‌شود. هیچ اعتبار نمایشی را به‌عنوان درآمد واقعی یا قابل برداشت معرفی نکنید.

## فایل‌های اصلی

- `app.py`: بک‌اند FastAPI و API
- `bot.py`: ربات تلگرام برای بازکردن Mini App
- `static/`: رابط کاربری
- `render.yaml`: تنظیمات استقرار خودکار روی Render
- `Procfile`: فرمان اجرای وب‌سرویس

## ۱) بارگذاری در GitHub

1. در GitHub یک repository جدید بسازید.
2. فایل‌های داخل این پوشه را در ریشه repository بارگذاری کنید (خود پوشه‌ی والد را داخل repository تو در تو نکنید).
3. مطمئن شوید `app.py` و `render.yaml` در ریشه repository هستند.
4. فایل `.env`، توکن ربات، دیتابیس و اطلاعات کاربران را هرگز در GitHub قرار ندهید.

## ۲) انتشار لینک عمومی با Render

GitHub محل نگهداری کد است؛ خودش برنامه Python/FastAPI را اجرا نمی‌کند. برای گرفتن لینک عمومی:

1. در Render ثبت‌نام کنید و GitHub را متصل کنید.
2. گزینه **New → Blueprint** را بزنید.
3. repository همین پروژه را انتخاب کنید تا `render.yaml` خوانده شود.
4. برای متغیر `BOT_TOKEN` توکن رباتی را که از BotFather گرفته‌اید وارد کنید.
5. سرویس را Deploy کنید.
6. پس از پایان Deploy، Render یک نشانی HTTPS شبیه `https://iran-miner.onrender.com` می‌دهد.

سرویس رایگان Render ممکن است در صورت بی‌فعالیتی به حالت خواب برود و اولین بازدید بعدی با تأخیر باز شود. همچنین فایل SQLite روی دیسک موقت سرویس رایگان ماندگار نیست و ممکن است با راه‌اندازی مجدد یا Deploy از بین برود؛ برای نگهداری واقعی داده‌ها باید دیتابیس پایدار متصل شود. تا قبل از آن فقط با داده‌های آزمایشی کار کنید.

## ۳) اتصال Mini App به تلگرام

1. نشانی HTTPS ساخته‌شده در Render را بردارید.
2. در BotFather تنظیمات Mini App / Web App ربات را باز کنید و همین نشانی را ثبت کنید.
3. توکن همان ربات را فقط در Environment Variables سرویس Render و با نام `BOT_TOKEN` قرار دهید.
4. مقدار `DEMO_MODE` باید `0` باشد. هرگز حالت دمو را روی سرویس عمومی فعال نکنید.

فایل `bot.py` برای اجرای ربات با polling است و به‌صورت خودکار توسط سرویس وب Render اجرا نمی‌شود. برای اجرای آن باید یک worker/سرویس جداگانه یا محیط اجرای جداگانه داشته باشید. لینک وب‌اپ پس از استقرار وب‌سرویس در دسترس خواهد بود.

## اجرای محلی

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

سپس `http://127.0.0.1:8000` را باز کنید. برای تست محلی رابط، می‌توانید موقتاً `DEMO_MODE=1` تنظیم کنید؛ این حالت فقط برای تست محلی است و نباید روی سایت عمومی فعال شود.

## امنیت و حریم خصوصی

- رمز تلگرام را درخواست یا ذخیره نکنید.
- توکن ربات را در کد یا GitHub قرار ندهید.
- `.env`، فایل‌های SQLite، کلیدها و اطلاعات کاربران را commit نکنید.
- قبل از استفاده عمومی، دیتابیس پایدار، پشتیبان‌گیری، محدودسازی درخواست‌ها، ثبت رویدادهای مدیریتی و بررسی امنیتی لازم است.
